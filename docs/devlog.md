## 2026-11-11　從一個原型開始

- **起點**：想做一款塔防遊戲，要有隨機地圖、可以蓋兵力和建築、可以升級，兵力之間要有單位碰撞，而且對電腦負擔不大
- 先做了一個**單檔 2D Canvas 原型**（現在放在 `prototype/`）：隨機路徑地圖、箭塔／砲塔／冰塔／兵營／金礦、三級升級、士兵碰撞
- **參考作品**：They Are Billions（大量屍潮）、Wool at the Gates（毛線手工風）
- 決定先把**引擎和開發環境**打好，再慢慢開發

### 選技術
- 引擎：**Web + Three.js**（3D 小場景）。原本推薦 PixiJS，但選了 3D 之後改用 Three.js
- 理由：可以在內建瀏覽器直接執行、截圖、除錯，方便一起開發
- 用 winget 安裝 Node.js LTS，專案用 TypeScript + Vite

### 引擎完成的東西
- **模擬和畫面分離**：固定每秒 30 tick，畫面插值
- **單位用 typed arrays（SoA）**，搭配**空間雜湊**做碰撞與索敵
- **流場尋路**：所有敵人共用一張路線圖，繞路太遠就會拆牆
- **InstancedMesh**：每種單位只要一次 draw call
- **毛線風格**：程式產生的針織貼圖、縫線風格介面、毛線軸城堡和塔、綿羊士兵
- **開發者沙盒**：地圖種子、時間倍率、單步、生成屍潮、免費建造、流場顯示
- 壓力測試：2000 隻單位時模擬約 2.4ms／tick

## 2026-11-12　大量發想

一整天的腦力激盪，從主題、經濟、種族到終局，主要轉折：

1. **毛線 vs 火**：毛線怕火 → 敵人帶著火來 → 主題變成**守護大自然**
2. **經濟**：不要傳統的食物／木頭／金礦，改成毛線經濟；**資源無限但產量受限**
3. **挑戰性**：「不是無腦堆資源」成為第一條設計支柱
4. **規則簡單**：使用者希望「無腦一點、別太細節」，例如農田不需要輪作
5. **主角**：從「農民」到「動物小村落」，最後決定是**擬人化動物**；不把動物的特色拆下來當裝甲，而是**各種族運用自己的天賦**
6. **外交**：外交館＋親密度，跨局累積；外交分成**戰場救助**和**外交使者**兩種
7. **時間**：月份太久 → 週＋季節；日夜太強制 → 融入**攻擊主角附帶的天氣事件**
8. **終局**：大後期加成奇觀，最後一場**總攻擊，撐過去就贏**
9. **敵人**：好壞種族分開；現實動物的敵人打贏後有機會救回良善個體，奇幻生物不行

### GPT 圖片 → 3D 模型
- 想用 GPT 生成美術圖，再轉成 3D 放進遊戲
- 做法選「**充氣布偶**」：去背 → 距離場 → 離輪廓越遠越厚，正反兩面貼同一張圖，像兩片毛氈縫起來塞棉花；剛好符合毛線手工風
- 輪廓交給貼圖的 alpha 切，網格很粗：一隻單位約 780 個三角形，1700 隻同時在場仍順
- 可選的第二張剪影（正面 + 側面）決定每一層的厚度，比例更像真的 3D
- 沒有圖就用原本的程式模型；開發者面板可以熱重載圖片、即時調厚度和解析度
- 換了新電腦：重新用 winget 安裝 Node.js LTS

### 第一隻羊人
- 綿羊兵的程式模型從四腳羊改成**擬人化羊人村民**（參考概念圖 `sheepan.png`）：雙腳站立、蓬鬆羊毛頭、捲角、側伸的耳朵、米白上衣＋棕色短褲、蹄手蹄腳、小尾巴
- 全部用低段數幾何體組合、平面著色（邊角分明），一隻約 600 個三角形；2000 多隻同時在場，繪圖約 1.4ms
